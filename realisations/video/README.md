# Dossier Vidéo

Placez ici vos projets **vidéo et direction artistique**.

## Pour les vidéos
Importez les **liens YouTube/Vimeo** directement dans le fichier `videos.json` à la racine du portfolio.

## Pour les images
- Miniatures/affiches de vos projets vidéo
- `.jpg` ou `.png`, résolution min : 1200x800px

## Exemples de projets
- Yakro City
- Aftermovies d'événements
- Clips ou courts-métrages

## Organisation
```
video/
  ├── yakro-city-thumb.jpg
  ├── bal-heleis-aftermovie-thumb.jpg
  └── ...
```
