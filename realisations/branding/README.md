# Dossier Branding

Placez ici vos images de projets de **branding** (identités visuelles complètes).

## Format recommandé
- `.jpg` ou `.png`
- Résolution min : 1200x800px
- Nommez vos fichiers de manière claire : `nom-projet-01.jpg`

## Exemples de projets à mettre ici
- Identité visuelle Invictus Agency
- Chartes graphiques
- Déclinaisons de marque

## Organisation par projet
Vous pouvez créer des sous-dossiers par projet :
```
branding/
  ├── invictus-agency/
  │   ├── cover.jpg
  │   ├── logo.png
  │   └── mockup.jpg
  ├── hollywood-chez-georges/
  │   ├── cover.jpg
  │   └── ...
```
