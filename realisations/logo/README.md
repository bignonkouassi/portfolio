# Dossier Logo

Placez ici vos créations de **logos**.

## Format recommandé
- `.png` (fond transparent de préférence)
- `.svg` si disponible
- Résolution min : 800x800px
- Nommez vos fichiers : `nom-client-logo.png`

## Exemples de projets à mettre ici
- Logos pour entreprises
- Logos pour événements
- Variations de logos (versions couleur, noir & blanc, icône)

## Organisation
```
logo/
  ├── invictus-agency.png
  ├── hollywood-chez-georges.png
  ├── all-ta-genie-civil.png
  ├── yakro-city.png
  └── ...
```
