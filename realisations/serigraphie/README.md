# Dossier Sérigraphie

Placez ici vos réalisations de **sérigraphie numérique et textile**.

## Format recommandé
- `.jpg` ou `.png`
- Résolution min : 1200x800px
- Nommez vos fichiers : `nom-projet-01.jpg`

## Exemples de projets à mettre ici
- T-shirts imprimés
- Visuels préparés pour impression
- Photos des produits finis
- Avant/après impression

## Organisation
```
serigraphie/
  ├── tshirt-hollywood.jpg
  ├── impression-textile-01.jpg
  ├── controle-qualite.jpg
  └── ...
```
