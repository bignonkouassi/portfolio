# Dossier Flyer

Placez ici vos images de **flyers et supports print**.

## Format recommandé
- `.jpg` ou `.png`
- Résolution min : 1200x800px
- Nommez vos fichiers : `nom-projet-01.jpg`

## Exemples de projets à mettre ici
- Flyers événementiels
- Affiches publicitaires
- Brochures
- Programmes d'événements

## Organisation
```
flyer/
  ├── bal-heleis-2023.jpg
  ├── picnic-day-2025.jpg
  ├── happy-run.jpg
  └── ...
```
